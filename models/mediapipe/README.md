# MediaPipe-Modelle

Diese Modelle laufen lokal. Kamerabilder werden nicht an einen Online-Dienst
gesendet.

- `blaze_face_short_range.tflite`: MediaPipe Face Detector (short range)
- `pose_landmarker_lite.task`: MediaPipe Pose Landmarker Lite mit
  Segmentierungsmaske
- `selfie_segmenter.tflite`: nahe Personen und angeschnittene Oberkörper

Offizielle Modellquellen:

- https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/latest/blaze_face_short_range.tflite
- https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task
- https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite
